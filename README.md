# Mis herramientas HTML

Portal estático para GitHub Pages.

## Publicación
1. Crear repositorio público `mis-herramientas`.
2. Subir `index.html`, `control_ing.html`, `Presupuesto.html` y `README.md` a la raíz de la rama `main`.
3. En Settings > Pages, seleccionar Deploy from a branch, `main`, `/ (root)` y guardar.
4. Abrir `https://b3lc3bu-666.github.io/mis-herramientas/`.

## Privacidad
No subir `presupuesto.json` ni datos financieros personales al repositorio. Las aplicaciones usan `localStorage` y no sincronizan entre dispositivos. En Mi presupuesto se puede importar el JSON manualmente desde el dispositivo.
